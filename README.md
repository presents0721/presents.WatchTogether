# 视频陪看（一起看）（presents.WatchTogether）

让角色按**真实播放进度**陪主人看视频：浏览器扩展每秒上报 `<video>.currentTime`，
插件在本地 `127.0.0.1` 收下，按「先短后长」的段表算出当前段、交付点与预取窗口；
段末前提醒角色开口，暂停/拖动/换片/播完都有明确提示。

这是 Alife 的 C# 插件，按播放位置分段陪看。核心能力包括：B 站字幕直取、网页视频实时抓帧与拼图、
本地视频字幕对齐、语音转写（SenseVoice 优先 / whisper 兜底）、画面文字 OCR、事件时间轴。
不做 TTS，也不做悬浮窗。

**当前版本：2.4.7**（构建标记 `wt-2.4.3-sv`，排查“重载没生效”看控制台里的 Build）。

## 两种位置来源

- **浏览器**：扩展读页面里播放器自己的 `<video>.currentTime`，每秒上报，最准；网页视频首选。
- **桌面播放器**：读 Windows 系统媒体会话（SMTC），支持把播放状态/时间轴交给 Windows 媒体控制的应用，如 Media Player、PotPlayer、VLC、QQ/微信内置播放器等（取决于应用是否接入 SMTC）。
- 两者同时可用时，浏览器上报新鲜就优先浏览器，否则用桌面媒体；桌面播放器的暂停/跳转插件不能代操作，请在播放器里手动控制。
- 完全没接入 SMTC 的播放器读不到进度，只能手动 `watch_together(input="文件路径", cursor=秒数)` 或换一个支持 SMTC 的播放器。

## 1. 它怎么工作

```
浏览器页面 <video> ──每秒──> content.js ──> background.js ──POST──> 127.0.0.1:9377
                                                                   │
                                                          Alife「一起看」插件
                                                                   │
                                         段表 / 位置估计 / 暂停·拖动·换片检测
                                                                   │
                                       watch_together 工具 + 到点 Poke / 可选唤醒
```

- **位置是真值**：扩展读的是页面里播放器自己的 `currentTime`，比任何外部接口都准。
- **只在可见标签页上报**：两个带视频的标签页不会互相打架。
- **读到才信**：5 秒内算实时；在播但读数旧了按时钟外推，最多 60 秒；
  再久就承认不知道，不能拿死数据编台词。
- **暂停永远可信**：位置不会自己走，暂停时的读数就是当前位置。
- **字幕是白板式的**：工具只给「当前位置往前 120 秒、上次没给过」的句子，用「12 秒前」这种相对时间；不重复、不贴整段。
- **字幕只到此刻**：本地/外部/页面字幕都只给到当前播放位置，不剧透。
- **可以动手**：模型能请求暂停/继续/回退/跳到；命令在下一次上报执行（最多约 1 秒）。
- **随机搭话可选**：有动静、距上次提醒 90 秒、骰子命中才开一轮；默认关，开了每命中一次 = 一轮模型请求。

## 2. 段表：为什么开头短

默认阶梯 `1m → 2m → 3m → 4m → 5m（之后固定）`。

固定 5 分钟一段意味着第一次说话要等将近 5 分钟；开头短、逐段加长，用户刚点开视频
就能感到「它跟上了」。稳定后回到 5 分钟，长期成本和固定段一样。

- 稳定段长：`300` 秒
- 起步阶梯：`60,120,180,240`
- 交付点：段末前 `15` 秒（不是段末，卡在切换点最突兀）
- 窗口余量：`300` 秒（状态里展示「当前往后要照顾到哪」；当前版本按需读素材，不做后台建图预取）

这些都能在插件配置里改，工具调用也可以临时用 `segment` / `ramp` / `lead` 覆盖。

## 3. 安装

### 3.1 插件

把 `presents.WatchTogether` 整个目录放进：

```
<Alife 数据目录>\Storage\Plugins\presents.WatchTogether
```

重启 Alife（或触发插件重载）。插件会在 `Storage\Plugins\presents.WatchTogether\state.json`
记当前片子的段进度，在 `Storage\PluginData\presents.WatchTogether\frames\` 放抽帧缓存。

默认监听 `127.0.0.1:9377`。端口被占用或想换端口，在控制台里改「监听端口」。

### 3.2 浏览器扩展

1. 打开 Edge / Chrome 的扩展管理页，开启「开发者模式」。
2. 点「加载解压缩的扩展」，选本插件目录下的 `extension`。
3. 浏览器里打开视频并播放；点扩展图标，popup 应显示「已连上 127.0.0.1:9377」。
4. **升级后要重新加载扩展**（清单新增了 `tabCapture` / `offscreen` 权限，浏览器会要求确认）。
5. **抓画面：在视频标签页上点一下扩展图标就行**（2.3.1 起）——
   popup 会自动为当前标签页开始抓帧，显示「抓取中 · 已上传 N 帧」即成功。
   不用再找按钮（按钮仍然保留，可以手动停/开）。
   - 图标出现**红点「!」** = 插件已经在要画面、但抓帧还没开始 → 点一下图标即可。
   - 图标可能被收进地址栏右侧的「拼图」菜单里，建议点图钉固定，方便一眼看到红点。

如果改了插件端口，扩展 popup 里的端口也要改成一样（扩展会保存到 `chrome.storage.local`）。

扩展只在 `http://*/*` 与 `https://*/*` 页面里读取 `<video>`，并且只在标签页可见时上报。

## 4. 工具：`watch_together`

不给参数就是自动接上主人浏览器里正在播放的那一支。

```
watch_together()
```

返回示例：

```
[一起看] 《标题》
[来源] 浏览器扩展上报 · 播放中
[位置] 03:12 / 12:34 · 实时（刚读到；0.8 秒前上报）
[当前段] 3 段 03:00-05:00（剩 108 秒，交付点 04:45） · 全片约 6 段
[节奏] 还没到交付点（04:45 再开口）；现在沉默就好。
[字幕] 本地字幕 movie.srt · 新增 8 句
- 刚刚｜这句是刚看到的
- 12 秒前｜上一句
...
[提示] ...
```

网页视频没有本地字幕时，这一行会变成一句提醒（「不要编台词；可配置外部字幕文件」），不会空着。

常用参数：

| 参数 | 作用 |
|---|---|
| `statusOnly` | 只看桥接/位置/段状态，不取素材 |
| `cursor` | 手动指定播放位置（秒），不读浏览器 |
| `input` | 手动指定 URL / 本地文件（一般不要问主人要） |
| `segment` / `ramp` / `lead` | 临时覆盖段表 |
| `cells` | 每段抽几帧（本地视频 + ffmpeg） |
| `from` / `size` | 补看某一段，不计入交付 |
| `say` | 把想说的一句记进这一场（只记录，不发送、不配音） |
| `pause` / `play` / `seekBack` / `seekTo` | 请求暂停/继续/回退/跳到；命令在下一次上报时执行 |
| `waitForVideo` | 等视频出现，最多 20 秒 |
| `reset` | 结束这一场，清空进度 |
| `download` | 把当前 B 站视频下到本地（之后可走本地抽帧/转写） |
| `timeline` | 最近 15 段的事件时间轴（字幕摘句 + 画面文字） |
| `recap` + `minutes` | 复盘最近 N 分钟，默认 30 |
| `ocr` | 现在读一次当前帧的文字，不推进段进度 |

### 字幕白板与增量

字幕不走「整段复述」，而是像一块会滚动的白板：

- 只给当前位置往前 `120` 秒、且**上次工具返回到的位置之后**的句子；同一句不会被贴两遍。
- 时间用播放位置算相对时间（「刚刚」「12 秒前」「2.0 分前」），暂停时不会漂。
- 默认只给已经看过的字幕，不给未来（不剧透）；想预告把「字幕往后预告」调大。
- 超过 40 句只给最近 40 句，并标明「前面还有 N 句已省略」。
- 字幕文件换掉（外部文件修改时间变化）时游标自动归零。
- 用 `from/size` 补看时按整段给，不推进游标。
- 到点提醒只附最近 3 句，不附整段；完整字幕留在工具结果里。

这套口径刻意做成「游标式字幕白板」：只在真正有内容时才贴、空的时候不占上下文、同一句不重复。

### 到交付点时

插件会推一条：

```
[一起看·到点] 《标题》第 3 段 03:00-05:00 快到尾巴（当前 03:48，还剩 72 秒）。
[字幕] ...
现在可以说一两句；不要复述剧情，没有素材就不要编。
```

- 默认 `PokeOnDue=true`：只推一条提醒，不自动唤醒模型。
- `WakeOnDue=true`：到点主动叫醒模型说一句；受「最小间隔」与「每日上限」约束，
  默认关闭，避免没人看视频时白烧 token。
- 静默时段（如 `23:00-08:00`）内不提醒、不唤醒。

### 暂停 / 拖动 / 换片 / 播完

| 事件 | 行为 |
|---|---|
| 暂停 | 不提醒；位置读数仍然可信 |
| 恢复 | 按新位置继续，不补说暂停期间 |
| 拖动 > 60 秒 | 推一条「跳到/回看到 mm:ss」，3 分钟内不重复；回看部分不复读 |
| 换片（时长变化 > 1 秒或换 BV 号） | 推一条「换片了」；新片从新位置重新分段，不自动念旧片台词 |
| 播完 | 推一条「播完了」，让角色收尾或问下一支 |
| 断流 > 20 秒 | 不再自动提醒；超过 60 秒工具也判位置不可信，不按旧时间说话 |

## 5. 字幕与画面（三条素材通道）

网页视频不下载、不代理，但**台词和画面都不再是空白**：

### ① B 站平台字幕（自动，默认开）

```
URL 里的 BV 号 → x/web-interface/view 拿 aid/cid
             → x/player/wbi/v2（WBI 签名 + SESSDATA）拿字幕轨
             → 下载 subtitle_url 的 JSON（from/to/content）→ 时间轴
```

- **人工 CC 字幕**不登录也能拿；**AI 字幕（ai-zh）**通常要登录态。
- 登录态优先用本插件「B 站 SESSDATA」配置；留空会自动借用
  `presents.BiliScroll/credentials.json` 里已有的 SessData（同机部署不用填两遍）。
- 选轨优先级：人工中文 > AI 中文 > 任意中文 > 第一条。
- 缓存 30 分钟（可调），换片立即重拉。
- 实测：`BV1otokBpENn`（RAG 知识讲解）拿到 ai-zh **522 句**——这类视频页面 DOM 里根本没有字幕元素，
  走接口是唯一靠谱的方式。

### ② 网页视频实时抓帧（扩展 tabCapture，默认开）

```
本插件每到抓帧间隔 → 位置响应里带 capture:true
   → 扩展抓一帧：先试页面 canvas；跨域视频被 CORS 污染时自动切 tabCapture
   → 画面真的变了才 POST /api/frame（JPEG）
   → 插件落盘 frames/live/<会话>/<秒>.jpg，工具返回最近几张的路径
```

- 为什么必须 tabCapture：B 站 / YouTube 的视频流在跨域 CDN，`canvas.drawImage(video)` 会污染画布，
  `toDataURL` 直接抛 `SecurityError`；tabCapture 抓的是标签页合成画面，不受 CORS 限制。
- **只用前必须在扩展 popup 里点一次「开始抓画面」**（tabCapture 需要用户手势 + 该标签页在前台）。
- 画面变化检测：96×54 灰度、平均差 ≥ 阈值（默认 6）才上传 —— PPT 翻页必触发，静态页不重复传。
- 抓帧间隔默认 20 秒（可调 5–300），保留最近 12 张（可调），旧帧自动删。
- **PPT / 图表讲解类没有语音台词，画面就是内容本体**：模型看最近一张帧就能讲出这页在说什么。

### ③ 本地视频（原有通道）

1. 找同目录同名 `.srt` / `.vtt`（支持 `movie.zh.srt`）；
2. 按段取与 `[段首, 段末]` 重叠的句子，带时间戳，默认最多 1200 字；
3. 装了 ffmpeg 就按段抽 5 格缩略图（优先按字幕句时间点），并可拼 2×3 概览图。

### 抓帧预设（2.1 起，面板一键套用）

把 `presents.Video` 那套「内容场景 → 采样参数」的经验搬到了在线抓帧上。在线只抓「现在这一帧」，
所以间隔比离线抽帧长——角色不需要每一帧，只需要知道这页/这个镜头是什么。

| 预设 | 间隔 | 变化阈值 | 宽度 | 质量 | 保留 | 适合 |
|---|---|---|---|---|---|---|
| **讲解/PPT** | 8 秒 | 4 | 1600 | 78 | 24 | PPT 翻页多、字小，讲解类首选 |
| **论文/图表** | 6 秒 | 3 | 1920 | 80 | 30 | 图表公式密集，要读小字 |
| **快切资讯** | 10 秒 | 12 | 1600 | 75 | 20 | 快切 + 大标题，阈值调高防刷屏 |
| **通用（推荐）** | 20 秒 | 6 | 1280 | 72 | 12 | 剧情/教程/访谈，默认 |
| **影视省流** | 60 秒 | 14 | 960 | 65 | 6 | 只要偶尔看一眼，最省流量与 token |
| **B站扫片（学习流）** | 15 秒 | 6 | 768 | 70 | 20 | BiliScroll 那套实测值，长时间看课不心疼 |

### 画面概览拼图（2.2 起）

抓到的帧不逐张丢给模型，而是**先拼成一张 3 列长图**：

```
[画面·概览] ...\sheet_1234.jpg（3 列，从左上到右下依次：12:01、12:18、12:35）
[画面·路径] 最近一张：...\001234.jpg
```

- 一张拼图 = 1 次视觉调用；六张单帧 = 6 次。PPT 翻页多的时候差别很大。
- 配置：`LiveFrameSheet`（默认开）、`LiveFrameSheetCells`（4/6/9，默认 6；格数越多单格越小）。
- 少于 3 帧不拼，直接给单帧路径；拼图失败自动退化成逐帧。
- 提示词里会写明「先用这张扫一遍，只在需要读细节时再看单帧」。

怎么选：**画面里有字要读 → 讲解/PPT 或论文/图表；画面变化快但不重要 → 快切资讯；只是陪着看 → 影视省流。**
套用后五项仍可单项微调（面板下面就是那五个框）。

### 任意站点都支持（不只 B 站 / YouTube）

位置桥本来就是通用的（扩展读页面里的 `<video>.currentTime`），2.0 之后画面也通用（tabCapture 抓标签页）。
2.1 把**字幕**也做成通用：

| 站点类型 | 画面 | 字幕 |
|---|---|---|
| B 站 | ✅ 抓帧 | ✅ 平台 CC / AI 字幕（自动） |
| YouTube / 其他有字幕元素的站 | ✅ 抓帧 | ✅ 自动读页面字幕（`AutoPageCaption` 默认开）+ 内置常见选择器 |
| 类名很怪的自制页面 | ✅ 抓帧 | ✅ 在「自定义字幕选择器」填 CSS 选择器 |
| 完全没有字幕轨 | ✅ 抓帧 | 外部 SRT（任何 ASR 导出的都行） |

> 页面字幕只读「字幕元素」的文本，不读正文、评论、私信；只在当前可见标签页读。

### ④ 视频下载（B 站，2.3 起）

```
view 拿 cid → playurl(wbi, fnval=16) 拿 DASH 音视频流
→ 分别下载 → ffmpeg -c copy 合流成 mp4 → 存到「下载目录」
```

- 调用：`watch_together(download=true)`；角色也可以自己判断「这片值得留」时下。
- 未登录拿 480p（`qn=32`），填了 SESSDATA 通常能到 1080p；大会员 4K/HDR 不保证。
- 非 B 站链接会明确说「只支持 B 站」——没有通用抽取器（装 yt-dlp 才有）。
- 实测：1 分 41 秒的片子 → 7.6 MB mp4（852×480 / H.264 + AAC），下载+合流约 10 秒。
- 下完可以直接 `watch_together(input="那个 mp4 路径")`，之后走本地视频的抽帧/转写。

### ⑤ 语音转写（ASR，2.3 起，默认关）

给「有人声、没字幕」的视频补台词：Vlog、口播、播客。**纯 PPT 讲解没语音，不适用。**

```
扩展 tabCapture 顺带录标签页声音 → 每 20 秒一片（webm/opus）
→ POST /api/audio → ffmpeg 转 16k 单声道 float PCM
→ 框架本地识别器 SenseVoice（优先）→ 句级时间轴
→ （识别器不可用 / 超时 / 音乐兜底时才跑 whisper-cli -osrt）
→ 和平台字幕同一套窗口逻辑给模型
```

- 转写引擎：优先 **框架 SenseVoice**（中文更准、CPU 快一个量级、自带 VAD）；坐标不在 / 超时 / 音乐兜底才回退 `whisper-cli.exe` + `ggml-*.bin`（留空时自动从 PATH 或插件数据目录 `tools\whisper\` 找，面板可改）。
- 字幕源优先级：外部文件 → B 站平台字幕 → **本地转写** → 本地同名 → 页面字幕。
- 切片长度可在面板调（默认 10 秒；越短字幕越跟得上画面，SenseVoice 走 CPU、不占显存）。
- 字幕时间轴按切片起点对齐：扩展上报的 `pos` 是切片末尾，插件会用音频真实时长回推起点，不会整体晚一个切片。
- 字幕里会标引擎（`本地转写 SenseVoice（N 句）` / `本地转写 whisper（N 句）`），模型知道台词是怎么来的。
- 切片延迟约 10–20 秒（默认 10 秒一片）；陪看按段说话，够用。
- 2.3.3：ASR 加 Silero VAD 人声检测（识别前切掉纯 BGM，模型自动查找，约 0.84 MB）；SenseVoice 自带 VAD 不受影响。
- 2.3.5：ASR 与抓帧解耦——扩展可只开一条纯录音 tabCapture 流（画面抓取关着也能转写）；点扩展图标即按插件意愿自动授权。
- SenseVoice 单次转写有 20 秒上限（VAD 在"人声+伴奏"上偶发卡死/空转，超时自动回退 whisper）。

**怎么确认真的走了 SenseVoice**：控制台 ASR 状态显示 `可用 · SenseVoice（框架本地，int8）· 内置 VAD`；
`/api/state` 里 `frameworkAsr=true`；日志里转写引擎标 `本地转写 SenseVoice（N 句）`。
框架识别器不可用（没装 SenseVoice 模块 / `sherpa-onnx` 依赖缺失）时才退回 whisper，
状态会显示 whisper 模型名。**框架侧 SenseVoice 是另一个模块，本插件只是有就用、没有就退。**

#### 纯 BGM 的片子：转写会自己认输（2.3.2 起）

**PPT 讲解 + 背景音乐**这类视频没有语音，转写引擎却会硬"听"出东西。实测（whisper-base，20 秒纯伴奏）：

```
( 字幕:貝爾 )        ← 字幕组署名幻觉
```

现在规则：

1. **过滤**：字幕组署名、订阅/点赞套话、重复拟声（「啊啊啊啊」）、纯音乐符号 → 直接丢；
2. **连续 3 段没有真语音** → 判定本片是纯 BGM，**停用转写**（同时让扩展停止录音，省 CPU），状态里写明；
3. **字幕来自转写时仍然做 OCR**：不让假字幕把画面文字挡掉——PPT 的内容本来就在画面上。

状态里会看到类似：`这一段没人声（丢弃 1 句：字幕:貝爾）` → `本片只有背景音乐，转写已停用`。

配置项：`过滤音乐幻觉`（默认开）。若发现正常台词被误杀，可临时关掉。

### ⑥ 画面文字 OCR（2.4 起，默认开）

PPT / 图表 / 代码讲解类视频**没有语音台词**，内容全在画面文字里。这一路用 **Windows 自带 OCR** 读最近一帧：

```
实时帧 .jpg → Windows.Media.Ocr（zh-Hans / en-US）→ 清理（合并中文字间空格、过滤符号噪音）
→ [画面·文字] 第七章反向传播 / 损失函数0.42学习率le-3 / 梯度消失：深层网络权重更新过慢
```

- **零依赖、不出网**：系统组件，不装模型、不上传。
- OCR 实现由 `presents.Shared.Media` 公共库提供（本插件依赖它），与游戏陪玩、B站刷视频共用同一套清理规则。
- 触发条件：默认「无字幕时才 OCR」——字幕句数 ≥ 3 就不再读，省时间也省 token；
  想要字幕和画面都给，把 `OcrOnlyWhenNoSubtitle` 关掉。
- 工具也能单独触发：`watch_together(ocr=true)` 读一次当前帧文字，不推进段进度。
- 实测（1280×720 幻灯片）：标题、公式、要点都能读出；密集小字会漏——它是兜底，不是替代视觉模型。

### ⑦ 陪看事件时间轴（2.4 起）

每交付一段就记一条：**时间 / 段号 / 字幕来源 / 字幕摘句 / 画面文字 / 帧路径**，只存文本不存像素。

```
watch_together(timeline=true)          → 最近 15 段
watch_together(recap=true&minutes=30)  → 最近半小时复盘
```

有了它，角色能回答「刚才这半小时讲了什么」，而不只是「现在这一页是什么」。
事件存 `PluginData\presents.WatchTogether\events.json`，默认保留 200 条。

### 兜底：外部字幕文件

网页视频本身没有字幕文件时，如果别的工具能生成按时间轴的 `.srt/.vtt`，填到「外部字幕文件」：
每 2 秒看一次修改时间，变了就重读并重置游标；播放中持续追加也支持。

字幕源优先级：**外部文件 → B 站平台字幕 → 本地同名 → 页面 DOM 字幕**。

### 本地视频

如果 `input` 是本地文件（或扩展所在页面是 `file://`），插件会：

1. 找同目录同名 `.srt` / `.vtt`（也支持 `movie.zh.srt` 这种语言后缀）；
2. 按段取与 `[段首, 段末]` 重叠的句子，带时间戳，默认最多 1200 字；
3. 若装了 ffmpeg，按段抽 5 格缩略图，返回文件路径（可用视觉工具查看）。

字幕命名示例：

```
D:\videos\movie.mp4
D:\videos\movie.srt        ← 直接命中
D:\videos\movie.zh.srt     ← 也会命中
```

也可以在控制台配置「素材目录」，让字幕集中放在一个目录里。

### 外部字幕文件（网页视频也能有字幕）

网页视频本身没有字幕。如果别的工具能生成一份按视频时间轴的 `.srt/.vtt`，把它填到「外部字幕文件」：

- 插件每 2 秒看一次文件修改时间，变了就重读，并把字幕游标归零。
- 文件在播放中持续追加也可以（比如实时 ASR 正在写）；每次写入后等 2 秒再读。
- 时间轴比视频晚/早，用「外部字幕时间偏移（秒）」对齐；只有从录音开始生成的字幕才需要。
- 推荐：本地 Whisper / SenseVoice 生成 SRT；或 B 站字幕下载工具导出 SRT。插件不内置 ASR，也不下载字幕。
- 外部字幕同样会过滤字幕组套话、纯符号和相邻重复，避免 ASR 幻觉把「字幕由…提供」当成台词。

### ffmpeg

留空会自动找：`PATH` → `imageio-ffmpeg`（通过 `ALIFE_PYTHON` 或常见 Python 安装）
→ `C:\ffmpeg\bin` 等常见目录。找不到就明确降级为「不抽帧」，不会假装有画面。

## 7. 隐私与边界

- 只监听 `127.0.0.1`，不接受外部连接。
- 扩展默认只上报 `pos / dur / title / url / paused / ended`，只在可见标签页上报。
- 「读取视频字幕」默认关；开启后扩展额外读取视频字幕元素（B 站/YouTube 等）的文本，
  只发给本机插件；不读正文、评论、私信。
- 不上传；`state.json` 只记片名、地址和段进度指针，不记画面、字幕原文或逐秒位置。
- 不读页面正文、不碰 Cookie、不绕过 DRM/付费/区域限制。
- 不内置 TTS / yt-dlp；语音转写用框架本地识别器（SenseVoice），兜底才调本机 whisper-cli。
- `say` 只是记录角色准备说的话，不会发送、不会配音。

## 8.5 没有字幕轨的视频（常见）

有些片子（纪录片、老番、搬运）B 站**一条字幕轨都没有**——人工 CC 和 AI 字幕都没有。
实测例子：`BV11e4M6KESS`（武则天纪录片）登录态正常，`wbi/v2` 返回 0 轨。

这时插件会明说「这支视频在 B 站没有字幕轨；只能靠画面或语音转写」，不会让角色瞎编台词。可选：

| 做法 | 说明 |
|---|---|
| **开语音转写**（推荐） | 控制台开「启用语音转写」，扩展录标签页声音，每 20 秒一片交给框架 SenseVoice（不可用/超时才回退 whisper） |
| 靠画面 | 点扩展图标自动抓帧；OCR 会读画面文字（纪录片旁白没字就没辙） |
| 外部字幕 | 有其他工具生成的 SRT 就填「外部字幕文件」 |

另外：**播完还没到段交付点**时（短片、从中间开始看），2.3.1 起会自动补一次「片尾交付」——
把字幕尾巴 + 最近画面推给角色，让它能收个尾，而不是整场静默。

## 8.6 两个曾让整个插件"哑火"的坑（都修了）

排查"陪看没反应"时先后挖出两个根因，都不是配置问题：

1. **`OnUpdate`（Tick）根本没跑**：框架的 Update 在角色后台 / 未聚焦时不触发，
   导致交付点、抓帧调度、配置同步全部停摆。现在改为**模块自建 1.5 秒定时器**驱动
   （`StartTickTimer` + `SafeTick` 防重入），不依赖框架 tick；框架真 tick 了也只是多一次空转。
2. **ASR 状态跨线程 / 换片重置的三个细节**：`asrMuted` 加 `volatile`（转写线程写、tick 线程读）；
   `WantAsr` 每拍同步时尊重 `asrMuted`，不能被抓帧决策覆盖回 true；
   换片时先重置 BGM 判定再恢复转写，顺序错了会一直停在"已停用"。

构建标记 `wt-2.4.3-sv`（`WatchBridge.BuildTag`）会显示在状态里——排查"重载没生效"先看这个。

## 9. 已知限制

- **抓画面要在扩展里点一次**：tabCapture 需要用户手势 + 目标标签页在前台，所以「开始抓画面」必须手动点；换标签页 / 关闭标签页后要重开。角色开新视频时若没画面，先看扩展 popup 的状态。
- **B 站 AI 字幕需要登录态**：`ai-zh` 轨道不给未登录请求；拿不到时自动退回人工 CC，再没有就退到页面字幕 / 外部文件。番剧、付费课堂、直播不保证有字幕轨。
- **字幕是「到此为止」的**：平台字幕按当前位置给窗口，不剧透；拉到字幕前的那几条消息没有台词属正常，下一条就补上了。
- 网页视频仍**不下载、不代理**；抓帧只在本机 127.0.0.1 流转，不上传第三方。
- 转写优先用框架 SenseVoice；框架识别器不在或超时才回退 whisper-cli（讲解类没语音，转写也没用；有语音无字幕的视频也可以直接配外部 SRT）。
- 桌面播放器依赖应用接入 Windows 媒体会话（SMTC）。QQ/微信内置播放器、部分老播放器不提供 SMTC 时读不到进度，只能手动 `watch_together(input=..., cursor=...)` 或换支持 SMTC 的播放器。
- SMTC 的时间轴刷新频率因播放器而异，插件会按 `LastUpdatedTime` 补一点，但仍可能比浏览器扩展粗；需要精确到秒时优先用网页视频。
- 字幕只支持 SRT/VTT，不支持 ASS/图形字幕；外部字幕需要按视频时间轴。
- 页面字幕是实验功能：只认常见字幕元素，不是所有站点都有；没有时只按进度陪聊。
- 播放器控制需要扩展 1.1.0+；命令在下一次上报时执行，最多约 1 秒；页面不可见时不上报，命令会等。
- 随机搭话默认关；开了每命中一次 = 一轮模型请求，成本自己控。
- 不做 TTS；不做悬浮窗/聊天框。视频下载（B 站）与转写（框架 SenseVoice / whisper 兜底）是有的，引擎本身不内置。
- B 站分 P 切换会按时长变化判成换片；这是有意的保守策略。
- 扩展只在可见标签页上报。用户切到聊天窗口时位置会过期，这时工具会明确说「位置不可信」，
  不会拿旧时间编台词。
- 首次加载插件需要 Alife 重启/重载；本项目只保证源码编译通过，未在运行中的 Alife 里做端到端点击测试。
